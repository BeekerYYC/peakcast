Peakcast widget

Home-screen widgets run in the free Scriptable app.

  1. Install Scriptable from the App Store.
  2. Tap Copy widget script above.
  3. In Scriptable tap +, long-press the empty editor, tap Paste, then Done.
  4. Tap the new script once. A forecast preview should pop up.
  5. Add a Scriptable widget to your home screen, long-press it → Edit Widget: Script = your script, When Interacting = Run Script, Parameter = a Peakcast share link (or leave empty).
